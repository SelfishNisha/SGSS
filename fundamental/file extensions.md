# Screen sharing fundamentals

## File extensions

A file extension determines what type of file it is and how it is executed. The way a file is executed varies depending on its extension, meaning that file detection methods also vary depending on the extension.

You can identify the extension of any file by looking at the end of its name (provided that file extensions are enabled).

To enable file extensions, open File Explorer, go to the "View" tab, and enable the "File name extensions" option.

Some of the file extensions you will encounter most frequently when dealing with cheats are:

- .exe: The most common extension. It is used by most Windows programs and can be executed directly. (**Exe**cutable)

- .jar: The extension used by Java files. Java must be installed for them to run. (**J**ava **Ar**chive)

- .dll: The extension used by libraries, which are usually loaded or used by other programs, such as .exe files. (**D**ynamic **L**ink **L**ibrary)

- .bat: The extension used by CMD scripts. Windows also includes some of its own. (**Bat**ch)

- .ps1: The extension used by PowerShell scripts. Windows also includes some built-in scripts. (**P**ower**S**hell) (where does the 1 come from? :|)

- .py: The extension used by Python programs. Python must be installed for them to run. (**Py**thon)

- .ahk: The extension used by AutoHotkey scripts. (**A**uto**H**ot**K**ey)

- .au3: The extension used by AutoIt scripts. (**Au**toIt)

- .pf: The extension used by Prefetch files. (**P**re**f**etch)

- .tmp: The extension used by temporary files. (**T**e**m****p**orary)

You may also come across the term PE (Portable Executable), which usually refers to .exe and .dll files.

As an additional note, there are obviously many more file extensions, but these are the ones you are most likely to encounter.
