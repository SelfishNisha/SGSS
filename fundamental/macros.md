# Screen sharing fundamentals

## Macros

A macro is a recorded action that can be repeated indefinitely or until it is instructed to stop.

Recording an action requires a program or, in the case of gaming mice, the mouse manufacturer's software.

Using macro functions, you can perform actions such as recording clicks and having them automatically repeat, just like an autoclicker.

Incase you'd like to learn about macros in detail, you can check out [Satella](https://github.com/selfishnisha/satella)
